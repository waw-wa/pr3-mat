# Практична робота № 3: Умовна ймовірність, теореми додавання та множення ймовірностей у діагностиці та аналізі програмних систем

Цей репозиторій містить програмну реалізацію, графіки та звіт для практичної роботи № 3 з дисципліни «Теорія ймовірностей та математична статистика».

---

## Загальна інформація
* **Дисципліна:** Теорія ймовірностей та математична статистика
* **Тема:** Умовна ймовірність та надійність розподілених систем
* **Варіанти завдань:**
  * **Блок 2:** Варіант 2 (Двофакторна автентифікація 2FA)
  * **Блок 4:** Варіант 8 (API Rate Limiter)

## Структура репозиторію

